# Қалам — қазақ тіліндегі мәтіндерді жазуға арналған веб-құрал

Облыстық байқау «Қазақ тілін қолдануға арналған IT өнімдер» үшін әзірленген екінші өнім. Бұл жолы негізгі бағыт — мәтін редакторы: кез келген адам өз сөйлемін қазақ тілінде жазып, грамматикалық қателерді автоматты түрде таба алады, баға алып, күнделікті үзінділермен шабыт алады.

## ✨ Мүмкіндіктер
- Қазақ тілінің ережелері бойынша 9 түрлі автоматты тексеру (бас әріп, тыныс белгілері, бос орындар, қайталама сөздер, ұзын сөйлемдер, латын әріптері, сандар, қысқа мәтін, соңғы тыныс белгісі).
- 0–100 баға жүйесі, түсті көрсеткіш.
- Статистика: сөз, таңба, сөйлем саны, қате саны.
- Күнделікті жұмбақ үзінді (5 даналық сөз).
- XP және 7 күндік серия (streak) жүйесі — localStorage арқылы сақталады.
- Көшіру/тазарту/үлгі мәтін батырмалары.
- Толықтай қазақ тіліндегі интерфейс, mobile-first адаптив дизайн.

## 🚀 Іске қосу
`index.html` файлын браузерде ашыңыз (Chrome/Edge ұсынылады).
